# Teacher Tools

A free, no-sign-up collection of classroom tools built as a static website for GitHub Pages.

## Included pages

- `index.html` — homepage
- `display-board.html` — automatic display board
- `report-assistant.html` — report assistant interface
- `student-selector.html` — random student selector
- `group-maker.html` — random group maker
- `classroom-timer.html` — classroom timer
- `classroom-screen.html` — classroom screen

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, such as `teacher-tools`.
2. Upload every file in this folder to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)` folder, then save.
6. GitHub will publish the website at a Pages address similar to:
   `https://YOUR-USERNAME.github.io/teacher-tools/`

## Privacy

Class lists, classroom-screen content and display-board settings are saved in browser local storage. They are not uploaded by these static pages.

The weather cards request public forecast information from Open-Meteo.
